# Behavioral Mechanism Library — Sources (V1)

Every mechanism in `behavioral_mechanisms.json` cites the original/authoritative academic source
in its `Source_References` field. This file lists the same references grouped by mechanism for
human reading, plus the full reference list deduplicated.

No source in this library was fabricated. Where a citation could not be confidently verified,
the entry would carry `SOURCE_REVIEW_REQUIRED` instead of an invented reference — no entry in V1
required this.

## Note on verification

These are well-established, widely-cited works in behavioral economics and psychology. Exact
volume/issue/page numbers are intentionally omitted where not confidently verifiable, rather
than inventing precise-looking but unverified detail — author, year, title, and publication
venue are sufficient to locate each source. If you want DOI-level precision for citing in a
formal document, verify each entry against Google Scholar or the publisher before external use.
