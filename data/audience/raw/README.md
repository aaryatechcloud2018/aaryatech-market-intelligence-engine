# data/audience/raw/

Raw, append-only audience data per platform (`reddit_raw.csv`,
`google_play_raw.csv`, `app_store_raw.csv`, `youtube_raw.csv`). Generated by
running `python -m src.audience_collection.run_collection` from an
environment with internet access — see `data/audience/README.md` for full
context. Currently empty: no live collection has run yet.

Existing rows in these files must never be edited or deleted by hand —
`src/audience_collection/collectors/base.py::append_new_raw_rows` is the
only code path that should write here, and it only ever appends.
